# OG Importing & Exporting LLC

Production-ready Next.js (App Router + TypeScript) website.

## Stack
- Next.js 15 (App Router) + React 19
- TypeScript
- No CSS framework — design tokens + hand-written CSS in `app/globals.css`
- Vercel-ready

## Local development
```bash
npm install
cp .env.example .env.local   # optional
npm run dev
# http://localhost:3000
